### [理音 TuneTidy](https://github.com/xhhhz/tunetidy) <!-- 仓库公开后确认链接 -->

一个开源的网易云音乐歌单整理工具（非官方），能把一个大歌单按曲风自动拆成多个小歌单。

- **按官方曲风分类**：默认不依赖大模型，直接读取平台已有的曲风标签，同一份数据快照下结果可复现
- **确认后再写入**：先生成"整理方案"，在本地网页里审阅、调整，人工批准后才写回账号；写回可续传、可撤销
- **支持 AI 助手调用**：提供 MCP 服务，Claude Code 等 AI 助手可以调用，但批准只能由人在终端完成

`Python` `Typer` `FastAPI` `React` `SQLite` `MCP`
